# ATS Mini Remote — releases

**Українська** · [Русский](#русский) · [English](#english)

Застосунок-пульт для кишенькового приймача **ATS Mini** (SI4732 + ESP32-S3): Android 6+ і Windows, підключення по Bluetooth, USB або Wi-Fi. Тут лише готові файли, вихідний код у приватному репозиторії.

* **Застосунок:** [остання версія](https://github.com/alexsumf-blip/ats-mini-remote-releases/releases/latest) — `ATS-Mini-Remote-X.Y.Z.apk` для Android, `ATS-Mini-Remote-Setup-X.Y.Z.msi` або portable ZIP для Windows.
* **Прошивка 2.46-uaN** (неофіційна, на базі [ATS Mini 2.46](https://github.com/esp32-si4732/ats-mini)): українська й російська мова екрана, дні тижня в розкладі EiBi, розширені команди для застосунку. Шукайте релізи `firmware-v…` у [списку релізів](https://github.com/alexsumf-blip/ats-mini-remote-releases/releases). Прошивка по Wi-Fi: Update → Manual upload → файл `…-ota.bin` свого варіанта (OSPI або QSPI).

Застосунок працює і зі стоковою прошивкою; розширені функції вмикаються самі з прошивкою uaN.

## Русский

Приложение-пульт для карманного приёмника **ATS Mini** (SI4732 + ESP32-S3): Android 6+ и Windows, подключение по Bluetooth, USB или Wi-Fi. Здесь только готовые файлы.

* **Приложение:** [последняя версия](https://github.com/alexsumf-blip/ats-mini-remote-releases/releases/latest).
* **Прошивка 2.46-uaN** (неофициальная, на базе ATS Mini 2.46): русский и украинский язык экрана, дни недели в расписании EiBi, расширенные команды. Релизы `firmware-v…` в [списке релизов](https://github.com/alexsumf-blip/ats-mini-remote-releases/releases). Прошивка по Wi-Fi: Update → Manual upload → файл `…-ota.bin` своего варианта (OSPI или QSPI).

## English

Remote-control app for the **ATS Mini** pocket receiver: Android 6+ and Windows, over Bluetooth, USB or Wi-Fi. Binaries only.

* **App:** [latest release](https://github.com/alexsumf-blip/ats-mini-remote-releases/releases/latest).
* **Firmware 2.46-uaN** (unofficial, based on ATS Mini 2.46): Ukrainian and Russian screen language, EiBi days of the week, remote extensions. See the `firmware-v…` releases.
